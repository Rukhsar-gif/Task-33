# Responsive Personal Portfolio Website

A professional and responsive personal portfolio website developed using **HTML5, CSS3, and JavaScript**. It showcases my profile, technical skills, projects, education, and web development experience.

The website is designed to provide a clean user experience across desktop, tablet, and mobile devices.

## Features

- **Home Section:** Introduction, professional title, and social profile links.
- **About Section:** Personal introduction, interests, and development goals.
- **Skills Section:** Programming languages, frontend technologies, backend tools, databases, and core concepts.
- **Projects Section:** Highlights selected development projects with technology tags.
- **Education & Experience:** Displays educational background and practical experience.
- **Contact Section:** Contact form with JavaScript validation.
- **Responsive Navigation:** Mobile-friendly menu with open and close functionality.
- **Responsive Layout:** Uses CSS Grid, Flexbox, and media queries.
- **Smooth Scrolling:** Navigation links move to the relevant sections.
- **Dynamic Footer:** Automatically displays the current year.
- **Accessibility:** Includes semantic HTML, keyboard focus styles, and accessible navigation attributes.

## Website Sections

### 1. Home
Introduces me as a Computer Science Engineering student interested in web development and software engineering. It includes links to my coding and professional profiles.

### 2. About Me
Provides an overview of my background, interests, and approach to learning software development.

### 3. Skills
Displays my technical skills, including Java, JavaScript, HTML, CSS, React.js, Node.js, Express.js, MongoDB, MySQL, Data Structures and Algorithms, and other development tools.

### 4. Projects

Includes a form for entering a name, email address, and message. JavaScript validates the fields and displays feedback.

**Note:** The contact form is currently a frontend demonstration. It validates the entered information but does not send messages to an email inbox.

## Responsive Design

The website adapts to different screen sizes using CSS media queries.

- **Desktop:** Multi-column layouts and horizontal navigation.
- **Tablet:** Adjusted grid layouts and spacing.
- **Mobile:** Single-column sections and collapsible navigation.

## JavaScript Functionality

JavaScript is used for:

- Opening and closing the mobile navigation menu.
- Closing the navigation menu after selecting a link.
- Displaying the current year in the footer.
- Validating contact form fields.
- Showing error and validation feedback.
